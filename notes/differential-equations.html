1Introduction to Differential Equations

1.1Basic Concepts

A differential equation (DE) is an equation that contains derivatives of an unknown function.

Examples: \[ \frac{dy}{dx} = 3x^2, \qquad y'' + 4y = 0, \qquad \frac{\partial u}{\partial t} = k\frac{\partial^2 u}{\partial x^2} \]

  • ODE (ordinary DE): one independent variable, so only ordinary derivatives like \(dy/dx\). This whole course.
  • PDE (partial DE): two or more independent variables, so partial derivatives like \(\partial u/\partial t\).

Order and degree

Definitions

Order = the order of the highest derivative in the equation.

Degree = the power of that highest derivative, after the equation has been cleared of radicals and fractions in the derivatives.

Example 1

\( y'' + 3y' + 2y = 0 \): highest derivative is \(y''\), power 1. Order 2, degree 1.

\( (y'')^3 + (y')^5 + y = x \): highest derivative \(y''\), raised to power 3. Order 2, degree 3. (The 5 on \(y'\) doesn't matter.)

\( \sqrt{1 + (y')^2} = y'' \): first square both sides to remove the root: \[ 1 + (y')^2 = (y'')^2 \] Order 2, degree 2.

Solutions

  • A solution is a function \(y = \phi(x)\) that makes the equation true when substituted in.
  • General solution: contains arbitrary constants (\(n\) constants for an \(n\)th-order ODE).
  • Particular solution: constants fixed by given conditions.
  • Singular solution: a solution that cannot be got from the general solution by choosing constants.
  • Initial value problem (IVP): DE + conditions at one point, e.g. \(y(0) = 1,\ y'(0) = 2\).
Example 2 · verify a solution

Show that \(y = e^{-x}\) solves \(y'' + 3y' + 2y = 0\).

Step 1. Differentiate: \(y' = -e^{-x}\), \(y'' = e^{-x}\).

Step 2. Substitute: \(e^{-x} + 3(-e^{-x}) + 2e^{-x} = (1 - 3 + 2)e^{-x} = 0\). ✓ It is a solution.

1.2Classification of ODEs

An \(n\)th-order ODE is linear if it can be written as

\[ a_n(x)\,y^{(n)} + a_{n-1}(x)\,y^{(n-1)} + \cdots + a_1(x)\,y' + a_0(x)\,y = g(x). \]
Linear means
  1. \(y\) and all its derivatives appear to power 1 only,
  2. no products like \(y\,y'\) or \((y')^2\),
  3. no functions of \(y\) like \(\sin y\), \(e^y\), \(\sqrt{y}\),
  4. the coefficients \(a_k\) depend on \(x\) only.

Otherwise it is non-linear.

More labels you'll see:

  • Homogeneous (linear): \(g(x) = 0\). Non-homogeneous: \(g(x) \ne 0\).
  • Constant coefficients: every \(a_k\) is a number. Variable coefficients: some \(a_k\) depend on \(x\).
  • Autonomous: \(x\) does not appear explicitly, e.g. \(y' = y(1 - y)\).

1.4Formation of Differential Equations

Given a family of curves with arbitrary constants, we form its DE by eliminating the constants.

Method
  1. Count the arbitrary constants, say \(n\).
  2. Differentiate the equation \(n\) times.
  3. Use the \(n + 1\) equations to eliminate all constants.

Result: a DE of order \(n\).

Example 1

Form the DE of \(y = Ax + A^2\).

Step 1. One constant, so differentiate once: \(y' = A\).

Step 2. Replace \(A\) by \(y'\): \[ \boxed{\,y = x y' + (y')^2\,} \]

(This is a Clairaut equation, order 1.)

Example 2

Form the DE of \(y = Ae^{2x} + Be^{-x}\).

Step 1. Two constants, so differentiate twice: \[ y' = 2Ae^{2x} - Be^{-x}, \qquad y'' = 4Ae^{2x} + Be^{-x}. \]

Step 2. Subtract: \(y'' - y' = 2Ae^{2x} + 2Be^{-x} = 2y\).

Step 3. \[ \boxed{\,y'' - y' - 2y = 0\,} \]

Check: roots of \(m^2 - m - 2 = 0\) are \(2, -1\), which match \(e^{2x}, e^{-x}\). ✓ (You will see why in 3.1.)

Example 3

Form the DE of all circles centred at the origin, \(x^2 + y^2 = r^2\).

Step 1. One constant \(r\). Differentiate: \(2x + 2y\,y' = 0\).

Step 2. \[ \boxed{\,x + y\dfrac{dy}{dx} = 0\,} \]

2Solution of First Order Differential Equations

A first-order ODE has the form \(\dfrac{dy}{dx} = f(x, y)\), or \(M(x,y)\,dx + N(x,y)\,dy = 0\).

Which method? Check in this order
  • Only \(x\) on the right, \(y' = f(x)\)? Use direct integration (2.1).
  • Can you split it as \(g(x)\,h(y)\)? Use separation of variables (2.2).
  • Is it a function of \(y/x\) only? Use homogeneous, \(y = vx\) (2.3).
  • Is \(M_y = N_x\)? Use exact (2.4).
  • Is it \(y' + P(x)y = Q(x)\)? Use linear, integrating factor (2.5).
  • Is it \(y' + P(x)y = Q(x)y^n\)? Use Bernoulli (2.6).
  • None of these? Try a substitution that reduces it (2.7).

2.1Direct Integration

If \(\dfrac{dy}{dx} = f(x)\), integrate both sides: \(y = \displaystyle\int f(x)\,dx + C\).

Example 1

Solve \(\dfrac{dy}{dx} = 3x^2 + e^x\), \(y(0) = 2\).

Step 1. Integrate: \(y = x^3 + e^x + C\).

Step 2. Use \(y(0) = 2\): \(2 = 0 + 1 + C \Rightarrow C = 1\).

Answer. \(\boxed{y = x^3 + e^x + 1}\)

Example 2 · second order

Solve \(y'' = 6x\).

Step 1. Integrate once: \(y' = 3x^2 + C_1\).

Step 2. Integrate again: \(\boxed{y = x^3 + C_1x + C_2}\)

Two integrations give two constants, matching order 2.

2.2Variable Separable Equations

Form \[ \frac{dy}{dx} = g(x)\,h(y) \]
  1. Separate: \(\dfrac{dy}{h(y)} = g(x)\,dx\) (all \(y\) on the left, all \(x\) on the right).
  2. Integrate both sides; put one constant \(C\) on one side.
  3. Solve for \(y\) if you can.
Example 1

Solve \(\dfrac{dy}{dx} = xy\).

Step 1. \(\dfrac{dy}{y} = x\,dx\)

Step 2. \(\ln|y| = \dfrac{x^2}{2} + C\)

Step 3. \(|y| = e^{C}e^{x^2/2}\), so \(\boxed{y = Ae^{x^2/2}}\) with \(A = \pm e^C\).

\(y = 0\) is also a solution (it was lost when dividing by \(y\)); it is covered by \(A = 0\).

Example 2

Solve \(\dfrac{dy}{dx} = \dfrac{1 + y^2}{1 + x^2}\).

Step 1. \(\dfrac{dy}{1 + y^2} = \dfrac{dx}{1 + x^2}\)

Step 2. \(\boxed{\tan^{-1} y = \tan^{-1} x + C}\)

Example 3 · IVP

Solve \(\dfrac{dy}{dx} = -\dfrac{x}{y}\), \(y(0) = 3\).

Step 1. \(y\,dy = -x\,dx\)

Step 2. \(\dfrac{y^2}{2} = -\dfrac{x^2}{2} + C \Rightarrow x^2 + y^2 = 2C\)

Step 3. At \((0, 3)\): \(9 = 2C\). Answer \(\boxed{x^2 + y^2 = 9}\), a circle of radius 3.

2.3Homogeneous Differential Equations

\(f(x,y)\) is homogeneous of degree \(n\) if \(f(tx, ty) = t^n f(x,y)\). The equation \(\dfrac{dy}{dx} = f(x,y)\) is homogeneous if \(f(tx,ty) = f(x,y)\), i.e. \(f\) is really a function of \(\dfrac{y}{x}\).

Method: put \(y = vx\)
  1. Let \(y = vx\), so \(\dfrac{dy}{dx} = v + x\dfrac{dv}{dx}\).
  2. Substitute. The \(x\)'s cancel on the right side.
  3. The result is separable in \(v\) and \(x\). Solve it.
  4. Put back \(v = \dfrac{y}{x}\).
Example 1

Solve \(\dfrac{dy}{dx} = \dfrac{x^2 + y^2}{xy}\).

Check. \(\dfrac{t^2x^2 + t^2y^2}{t^2xy} = \dfrac{x^2 + y^2}{xy}\), so it is homogeneous. ✓

Step 1. \(y = vx\): \(\ v + x\dfrac{dv}{dx} = \dfrac{x^2 + v^2x^2}{vx^2} = \dfrac{1 + v^2}{v} = \dfrac{1}{v} + v\)

Step 2. \(x\dfrac{dv}{dx} = \dfrac{1}{v} \Rightarrow v\,dv = \dfrac{dx}{x}\)

Step 3. \(\dfrac{v^2}{2} = \ln|x| + C\)

Step 4. \(v = y/x\): \(\boxed{y^2 = 2x^2\left(\ln|x| + C\right)}\)

Example 2

Solve \(\dfrac{dy}{dx} = \dfrac{x + y}{x}\).

Step 1. \(v + xv' = 1 + v \Rightarrow xv' = 1\)

Step 2. \(dv = \dfrac{dx}{x} \Rightarrow v = \ln|x| + C\)

Step 3. \(\boxed{y = x\ln|x| + Cx}\)

This one is also linear (\(y' - y/x = 1\)). Many equations fit more than one method.

2.4Exact Differential Equations

\(M\,dx + N\,dy = 0\) is exact if there is a function \(F(x,y)\) with \(dF = M\,dx + N\,dy\). The solution is then \(F(x,y) = C\).

Test and method \[ \text{Exact} \iff \frac{\partial M}{\partial y} = \frac{\partial N}{\partial x} \]
  1. Check \(M_y = N_x\).
  2. Integrate \(M\) with respect to \(x\) (holding \(y\) constant): \(F = \int M\,dx + g(y)\).
  3. Differentiate \(F\) with respect to \(y\) and set it equal to \(N\). This gives \(g'(y)\).
  4. Integrate to get \(g(y)\). Write \(F(x,y) = C\).
Example 1

Solve \((2xy + 3)\,dx + (x^2 + 4y)\,dy = 0\).

Step 1. \(M_y = 2x,\ N_x = 2x\). Equal, so exact. ✓

Step 2. \(F = \int (2xy + 3)\,dx = x^2y + 3x + g(y)\)

Step 3. \(F_y = x^2 + g'(y) = x^2 + 4y \Rightarrow g'(y) = 4y\)

Step 4. \(g(y) = 2y^2\). Answer \(\boxed{x^2y + 3x + 2y^2 = C}\)

Example 2

Solve \((e^x\sin y + 2x)\,dx + e^x\cos y\,dy = 0\).

Step 1. \(M_y = e^x\cos y = N_x\). Exact. ✓

Step 2. \(F = e^x\sin y + x^2 + g(y)\)

Step 3. \(F_y = e^x\cos y + g'(y) = e^x\cos y \Rightarrow g' = 0\)

Answer. \(\boxed{e^x\sin y + x^2 = C}\)

Not exact? Use an integrating factor \(\mu\)

Two common cases

If \(\dfrac{M_y - N_x}{N} = f(x)\) (depends on \(x\) only), then \(\mu = e^{\int f(x)\,dx}\).

If \(\dfrac{N_x - M_y}{M} = g(y)\) (depends on \(y\) only), then \(\mu = e^{\int g(y)\,dy}\).

Multiply the whole equation by \(\mu\). It becomes exact.

Example 3

Solve \((3xy + y^2)\,dx + (x^2 + xy)\,dy = 0\).

Step 1. \(M_y = 3x + 2y,\ N_x = 2x + y\). Not equal, so not exact.

Step 2. \(\dfrac{M_y - N_x}{N} = \dfrac{x + y}{x(x + y)} = \dfrac{1}{x}\), a function of \(x\) only. So \(\mu = e^{\int dx/x} = x\).

Step 3. Multiply by \(x\): \((3x^2y + xy^2)\,dx + (x^3 + x^2y)\,dy = 0\). Now \(M_y = 3x^2 + 2xy = N_x\). ✓

Step 4. \(F = x^3y + \dfrac{x^2y^2}{2} + g(y)\); \(F_y = x^3 + x^2y + g' \Rightarrow g' = 0\).

Answer. \(\boxed{x^3y + \tfrac{1}{2}x^2y^2 = C}\)

2.5Linear Differential Equations

Standard form \[ \frac{dy}{dx} + P(x)\,y = Q(x) \]
  1. Make the coefficient of \(y'\) equal to 1 (divide through if needed).
  2. Integrating factor: \(\mu(x) = e^{\int P(x)\,dx}\).
  3. Multiply through. The left side becomes \(\dfrac{d}{dx}(\mu y)\).
  4. Integrate: \(\mu y = \displaystyle\int \mu Q\,dx + C\), then divide by \(\mu\).
\[ y = \frac{1}{\mu}\left(\int \mu\,Q\,dx + C\right) \]
Example 1

Solve \(y' + 2y = e^{-x}\).

Step 1. \(P = 2\), \(\mu = e^{2x}\).

Step 2. \(\dfrac{d}{dx}\left(e^{2x}y\right) = e^{2x}e^{-x} = e^{x}\)

Step 3. \(e^{2x}y = e^x + C\)

Answer. \(\boxed{y = e^{-x} + Ce^{-2x}}\)

Example 2

Solve \(xy' + y = x^3\), \(x > 0\).

Step 1. Divide by \(x\): \(y' + \dfrac{1}{x}y = x^2\). \(\mu = e^{\ln x} = x\).

Step 2. \(\dfrac{d}{dx}(xy) = x^3 \Rightarrow xy = \dfrac{x^4}{4} + C\)

Answer. \(\boxed{y = \dfrac{x^3}{4} + \dfrac{C}{x}}\)

Example 3 · IVP

Solve \(y' - y = 2x\), \(y(0) = 1\).

Step 1. \(\mu = e^{-x}\): \(\dfrac{d}{dx}(e^{-x}y) = 2xe^{-x}\)

Step 2. By parts, \(\int 2xe^{-x}dx = -2xe^{-x} - 2e^{-x}\). So \(e^{-x}y = -2xe^{-x} - 2e^{-x} + C\).

Step 3. \(y = -2x - 2 + Ce^{x}\). Then \(y(0) = 1 \Rightarrow -2 + C = 1 \Rightarrow C = 3\).

Answer. \(\boxed{y = 3e^{x} - 2x - 2}\)

Check: \(y' - y = (3e^x - 2) - (3e^x - 2x - 2) = 2x\). ✓

2.6Bernoulli's Differential Equation

Form \[ \frac{dy}{dx} + P(x)\,y = Q(x)\,y^n, \qquad n \ne 0, 1 \]
  1. Substitute \(v = y^{1-n}\).
  2. Then the equation becomes linear in \(v\): \[ \frac{dv}{dx} + (1 - n)P(x)\,v = (1 - n)Q(x) \]
  3. Solve with an integrating factor (2.5), then put \(y = v^{1/(1-n)}\).

Why? Divide by \(y^n\): \(y^{-n}y' + Py^{1-n} = Q\), and \(v' = (1-n)y^{-n}y'\).

Example 1

Solve \(y' + y = xy^2\).

Step 1. \(n = 2\), so \(v = y^{-1}\). The equation becomes \(v' - v = -x\).

Step 2. \(\mu = e^{-x}\): \(\dfrac{d}{dx}(e^{-x}v) = -xe^{-x}\)

Step 3. \(\int -xe^{-x}dx = xe^{-x} + e^{-x}\), so \(e^{-x}v = xe^{-x} + e^{-x} + C\) and \(v = x + 1 + Ce^{x}\).

Answer. \(\boxed{y = \dfrac{1}{x + 1 + Ce^{x}}}\)

Example 2

Solve \(x y' + y = x^2y^2\).

Step 1. Divide by \(x\): \(y' + \dfrac{1}{x}y = x\,y^2\). \(n = 2\), \(v = y^{-1}\): \[ v' - \frac{1}{x}v = -x \]

Step 2. \(\mu = e^{-\ln x} = \dfrac{1}{x}\): \(\dfrac{d}{dx}\left(\dfrac{v}{x}\right) = -1 \Rightarrow \dfrac{v}{x} = -x + C\)

Step 3. \(v = -x^2 + Cx\). Answer \(\boxed{y = \dfrac{1}{Cx - x^2}}\)

2.7Reducible Equations

These are equations that a substitution turns into one of the types above.

(a) \(\dfrac{dy}{dx} = \dfrac{a_1x + b_1y + c_1}{a_2x + b_2y + c_2}\)

Two cases

Case 1: \(\dfrac{a_1}{a_2} \ne \dfrac{b_1}{b_2}\) (lines cross). Solve \(a_1h + b_1k + c_1 = 0,\ a_2h + b_2k + c_2 = 0\). Put \(x = X + h,\ y = Y + k\). The result is homogeneous in \(X, Y\).

Case 2: \(\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2}\) (parallel lines). Put \(z = a_1x + b_1y\). The result is separable.

Example 1 · Case 1

Solve \(\dfrac{dy}{dx} = \dfrac{x + y - 2}{x - y}\).

Step 1. \(h + k - 2 = 0,\ h - k = 0 \Rightarrow h = k = 1\). Put \(x = X + 1,\ y = Y + 1\): \[ \frac{dY}{dX} = \frac{X + Y}{X - Y} \]

Step 2. \(Y = vX\): \(\ v + Xv' = \dfrac{1 + v}{1 - v} \Rightarrow Xv' = \dfrac{1 + v^2}{1 - v}\)

Step 3. Separate: \(\dfrac{1 - v}{1 + v^2}dv = \dfrac{dX}{X}\), so \[ \tan^{-1}v - \tfrac{1}{2}\ln(1 + v^2) = \ln|X| + C \]

Step 4. \(\ln|X| + \tfrac12\ln(1 + v^2) = \tfrac12\ln(X^2 + Y^2)\). With \(X = x - 1,\ Y = y - 1\): \[ \boxed{\tan^{-1}\!\left(\frac{y - 1}{x - 1}\right) = \tfrac{1}{2}\ln\!\left[(x - 1)^2 + (y - 1)^2\right] + C} \]

Example 2 · Case 2

Solve \(\dfrac{dy}{dx} = \dfrac{x + y + 1}{x + y - 1}\).

Step 1. Put \(z = x + y\), so \(\dfrac{dz}{dx} = 1 + \dfrac{dy}{dx} = 1 + \dfrac{z + 1}{z - 1} = \dfrac{2z}{z - 1}\).

Step 2. \(\dfrac{z - 1}{2z}dz = dx \Rightarrow \dfrac{1}{2}\left(z - \ln|z|\right) = x + C\)

Step 3. \(x + y - \ln|x + y| = 2x + 2C\), so \(\boxed{y - x - \ln|x + y| = K}\)

(b) Second-order equations reducible to first order

Two tricks with \(p = y'\)

\(y\) missing, i.e. \(F(x, y', y'') = 0\): put \(y' = p\), \(y'' = \dfrac{dp}{dx}\).

\(x\) missing, i.e. \(F(y, y', y'') = 0\): put \(y' = p\), \(y'' = p\dfrac{dp}{dy}\) (chain rule).

Example 3 · \(y\) missing

Solve \(xy'' - y' = 0\).

Step 1. \(p = y'\): \(x\dfrac{dp}{dx} = p \Rightarrow \dfrac{dp}{p} = \dfrac{dx}{x} \Rightarrow p = C_1x\)

Step 2. \(y' = C_1x \Rightarrow \boxed{y = \tfrac{C_1}{2}x^2 + C_2}\)

Example 4 · \(x\) missing

Solve \(y\,y'' = (y')^2\).

Step 1. \(y' = p,\ y'' = p\dfrac{dp}{dy}\): \(\ y\,p\dfrac{dp}{dy} = p^2 \Rightarrow \dfrac{dp}{p} = \dfrac{dy}{y}\)

Step 2. \(p = C_1y\), i.e. \(\dfrac{dy}{dx} = C_1y\)

Answer. \(\boxed{y = C_2e^{C_1x}}\)

2.8Applications of First Order Equations

(i) Growth and decay: \(\dfrac{dN}{dt} = kN\)

Separable: \(\boxed{N(t) = N_0e^{kt}}\). Growth if \(k > 0\), decay if \(k < 0\).

Example 1 · half-life

A substance has half-life 5 years. How much of 100 g is left after 12 years?

Step 1. Half-life: \(\tfrac12 = e^{5k} \Rightarrow k = -\dfrac{\ln 2}{5}\).

Step 2. \(N(12) = 100e^{-12\ln 2/5} = 100\cdot 2^{-2.4}\)

Answer. \(N(12) \approx 100 \times 0.1895 \approx \boxed{18.9\ \text{g}}\)

(ii) Newton's law of cooling: \(\dfrac{dT}{dt} = -k(T - T_s)\)

Separable: \(\boxed{T(t) = T_s + (T_0 - T_s)e^{-kt}}\).

Example 2

Tea at \(90^\circ\)C is left in a \(20^\circ\)C room. After 10 min it is \(60^\circ\)C. When will it reach \(40^\circ\)C?

Step 1. \(T = 20 + 70e^{-kt}\).

Step 2. \(60 = 20 + 70e^{-10k} \Rightarrow e^{-10k} = \tfrac47 \Rightarrow k = \tfrac{1}{10}\ln\tfrac74 \approx 0.0560\).

Step 3. \(40 = 20 + 70e^{-kt} \Rightarrow e^{-kt} = \tfrac27 \Rightarrow t = \dfrac{\ln 3.5}{k}\)

Answer. \(t \approx \dfrac{1.2528}{0.0560} \approx \boxed{22.4\ \text{min}}\)

(iii) RL circuit: \(L\dfrac{di}{dt} + Ri = E\)

Example 3

Constant \(E\), \(i(0) = 0\). Find \(i(t)\).

Step 1. Linear: \(i' + \dfrac{R}{L}i = \dfrac{E}{L}\), \(\mu = e^{Rt/L}\).

Step 2. \(e^{Rt/L}i = \dfrac{E}{R}e^{Rt/L} + C\), and \(i(0) = 0 \Rightarrow C = -\dfrac{E}{R}\).

Answer. \(\boxed{i(t) = \dfrac{E}{R}\left(1 - e^{-Rt/L}\right)}\). As \(t \to \infty\), \(i \to E/R\) (Ohm's law).

(iv) Orthogonal trajectories

Curves that cut every member of a family at right angles. Method: find the family's DE \(y' = f(x,y)\), replace \(y'\) by \(-\dfrac{1}{y'}\), and solve.

Example 4

Find the orthogonal trajectories of \(y = cx^2\).

Step 1. \(y' = 2cx\) and \(c = y/x^2\), so \(y' = \dfrac{2y}{x}\).

Step 2. Replace: \(y' = -\dfrac{x}{2y}\), so \(2y\,dy = -x\,dx\).

Answer. \(y^2 = -\dfrac{x^2}{2} + C\), i.e. \(\boxed{x^2 + 2y^2 = K}\), a family of ellipses.

  7. Orthogonal trajectories of \(xy = c\).
    \(y' = -y/x\) becomes \(y' = x/y\): \(y^2 - x^2 = K\).

3Second Order Differential Equations

General linear second-order ODE:

\[ a(x)\,y'' + b(x)\,y' + c(x)\,y = g(x) \]
Key facts
  • The homogeneous equation (\(g = 0\)) has two linearly independent solutions \(y_1, y_2\). Its general solution is \(y_c = C_1y_1 + C_2y_2\) (the complementary function).
  • Independence test, the Wronskian: \(W(y_1, y_2) = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} = y_1y_2' - y_1'y_2 \ne 0\).
  • For \(g \ne 0\): \(\boxed{y = y_c + y_p}\), where \(y_p\) is any particular integral.

3.1Linear Differential Equations with Constant Coefficients

\(ay'' + by' + cy = 0\) with \(a, b, c\) constants. Try \(y = e^{mx}\): then \(y' = me^{mx},\ y'' = m^2e^{mx}\), and

\[ e^{mx}(am^2 + bm + c) = 0 \quad\Rightarrow\quad \boxed{am^2 + bm + c = 0} \]

This is the auxiliary (characteristic) equation. Everything depends on its roots.

The three cases
RootsComplementary function \(y_c\)
Real, distinct \(m_1 \ne m_2\)\(C_1e^{m_1x} + C_2e^{m_2x}\)
Real, repeated \(m_1 = m_2 = m\)\((C_1 + C_2x)e^{mx}\)
Complex \(\alpha \pm i\beta\)\(e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)\)
Example 1 · distinct

\(y'' - 5y' + 6y = 0\)

Step 1. \(m^2 - 5m + 6 = (m - 2)(m - 3) = 0 \Rightarrow m = 2, 3\)

Answer. \(\boxed{y = C_1e^{2x} + C_2e^{3x}}\)

Example 2 · repeated

\(y'' - 4y' + 4y = 0\)

Step 1. \((m - 2)^2 = 0 \Rightarrow m = 2, 2\)

Answer. \(\boxed{y = (C_1 + C_2x)e^{2x}}\)

The extra \(x\) is needed because \(e^{2x}\) twice is not two independent solutions.

Example 3 · complex

\(y'' + 2y' + 5y = 0\)

Step 1. \(m = \dfrac{-2 \pm \sqrt{4 - 20}}{2} = -1 \pm 2i\), so \(\alpha = -1,\ \beta = 2\).

Answer. \(\boxed{y = e^{-x}(C_1\cos 2x + C_2\sin 2x)}\)

Example 4 · IVP

\(y'' + 4y = 0,\ y(0) = 1,\ y'(0) = 2\)

Step 1. \(m^2 + 4 = 0 \Rightarrow m = \pm 2i\), so \(y = C_1\cos 2x + C_2\sin 2x\).

Step 2. \(y(0) = C_1 = 1\). \(y' = -2C_1\sin 2x + 2C_2\cos 2x\), so \(y'(0) = 2C_2 = 2 \Rightarrow C_2 = 1\).

Answer. \(\boxed{y = \cos 2x + \sin 2x}\)

Example 5 · higher order (same idea)

\(y''' - 6y'' + 11y' - 6y = 0\)

Step 1. \(m^3 - 6m^2 + 11m - 6 = 0\). Try \(m = 1\): \(1 - 6 + 11 - 6 = 0\) ✓. Factor: \((m - 1)(m - 2)(m - 3) = 0\).

Answer. \(\boxed{y = C_1e^{x} + C_2e^{2x} + C_3e^{3x}}\)

3.2Non-Homogeneous Equations

\(ay'' + by' + cy = g(x)\), \(g \ne 0\). Always work in this order:

Plan
  1. Find \(y_c\) from the auxiliary equation (3.1).
  2. Find one particular integral \(y_p\) (3.2.1, 3.2.2 or 3.4).
  3. Write \(y = y_c + y_p\). Apply initial conditions last, to the full \(y\).

3.2.1 Method of Undetermined Coefficients

Works when \(g(x)\) is a polynomial, exponential, sine/cosine, or sums and products of these. Guess a \(y_p\) of the same shape with unknown constants, substitute, and match coefficients.

\(g(x)\)Trial \(y_p\)
\(k\) (constant)\(A\)
polynomial of degree \(n\)\(A_nx^n + \cdots + A_1x + A_0\)
\(ke^{ax}\)\(Ae^{ax}\)
\(k\cos\beta x\) or \(k\sin\beta x\)\(A\cos\beta x + B\sin\beta x\) (always both)
\(e^{ax}\times\) polynomial\(e^{ax}(A_nx^n + \cdots + A_0)\)
\(e^{ax}\cos\beta x\)\(e^{ax}(A\cos\beta x + B\sin\beta x)\)
Modification rule ⚠

If any term of your trial \(y_p\) already appears in \(y_c\), multiply the trial by \(x\). If it still clashes (repeated root), multiply by \(x^2\).

Example 1 · polynomial

\(y'' - 3y' + 2y = 4x\)

Step 1. \(m^2 - 3m + 2 = 0 \Rightarrow m = 1, 2\). \(y_c = C_1e^x + C_2e^{2x}\).

Step 2. Trial \(y_p = Ax + B\): \(y_p' = A,\ y_p'' = 0\).

Step 3. \(0 - 3A + 2(Ax + B) = 4x \Rightarrow 2Ax + (2B - 3A) = 4x\).

Step 4. Match: \(2A = 4 \Rightarrow A = 2\); \(2B - 3A = 0 \Rightarrow B = 3\).

Answer. \(\boxed{y = C_1e^x + C_2e^{2x} + 2x + 3}\)

Example 2 · exponential

\(y'' + y' - 2y = e^{3x}\)

Step 1. \((m + 2)(m - 1) = 0\): \(y_c = C_1e^{x} + C_2e^{-2x}\).

Step 2. \(y_p = Ae^{3x}\): \(9A + 3A - 2A = 10A = 1 \Rightarrow A = \tfrac{1}{10}\).

Answer. \(\boxed{y = C_1e^{x} + C_2e^{-2x} + \tfrac{1}{10}e^{3x}}\)

Example 3 · trig

\(y'' + 4y = 3\sin x\)

Step 1. \(m = \pm 2i\): \(y_c = C_1\cos 2x + C_2\sin 2x\).

Step 2. \(y_p = A\cos x + B\sin x\), \(y_p'' = -A\cos x - B\sin x\).

Step 3. \(3A\cos x + 3B\sin x = 3\sin x \Rightarrow A = 0,\ B = 1\).

Answer. \(\boxed{y = C_1\cos 2x + C_2\sin 2x + \sin x}\)

Example 4 · modification rule

\(y'' - 3y' + 2y = e^{x}\)

Step 1. \(y_c = C_1e^x + C_2e^{2x}\). The trial \(Ae^x\) is already in \(y_c\), so use \(y_p = Axe^x\).

Step 2. \(y_p' = A(1 + x)e^x,\ y_p'' = A(2 + x)e^x\).

Step 3. \(A\big[(2 + x) - 3(1 + x) + 2x\big]e^x = -Ae^x = e^x \Rightarrow A = -1\).

Answer. \(\boxed{y = C_1e^x + C_2e^{2x} - xe^{x}}\)

3.2.2 Variation of Parameters

Works for any \(g(x)\), e.g. \(\sec x\), \(\tan x\), \(\ln x\), \(e^x/x\), where undetermined coefficients fails.

Formula

First write the equation as \(y'' + P(x)y' + Q(x)y = f(x)\) (coefficient of \(y''\) must be 1). With \(y_c = C_1y_1 + C_2y_2\) and \(W = y_1y_2' - y_1'y_2\):

\[ y_p = u_1y_1 + u_2y_2, \qquad u_1 = -\int \frac{y_2\,f}{W}\,dx, \qquad u_2 = \int \frac{y_1\,f}{W}\,dx \]
Example 1

\(y'' + y = \sec x\)

Step 1. \(y_1 = \cos x,\ y_2 = \sin x\). \(W = \cos x\cos x - (-\sin x)\sin x = 1\).

Step 2. \(u_1 = -\int \sin x\sec x\,dx = -\int\tan x\,dx = \ln|\cos x|\)

Step 3. \(u_2 = \int \cos x\sec x\,dx = \int 1\,dx = x\)

Answer. \(\boxed{y = C_1\cos x + C_2\sin x + \cos x\ln|\cos x| + x\sin x}\)

Example 2

\(y'' - 2y' + y = \dfrac{e^x}{x}\)

Step 1. \((m - 1)^2 = 0\): \(y_1 = e^x,\ y_2 = xe^x\). \(W = e^x(1 + x)e^x - e^x\cdot xe^x = e^{2x}\).

Step 2. \(u_1 = -\int \dfrac{xe^x\cdot e^x/x}{e^{2x}}dx = -\int 1\,dx = -x\)

Step 3. \(u_2 = \int \dfrac{e^x\cdot e^x/x}{e^{2x}}dx = \int\dfrac{dx}{x} = \ln|x|\)

Step 4. \(y_p = -xe^x + xe^x\ln|x|\). The \(-xe^x\) part is already in \(y_c\), so drop it.

Answer. \(\boxed{y = (C_1 + C_2x)e^x + xe^x\ln|x|}\)

3.3Cauchy–Euler Equations

Form \[ ax^2y'' + bxy' + cy = 0 \qquad (x > 0) \]

The power of \(x\) matches the order of the derivative. Try \(y = x^m\): \(y' = mx^{m-1},\ y'' = m(m-1)x^{m-2}\). Then

\[ \boxed{am(m - 1) + bm + c = 0} \]
RootsSolution
Real, distinct \(m_1, m_2\)\(C_1x^{m_1} + C_2x^{m_2}\)
Repeated \(m\)\(x^m(C_1 + C_2\ln x)\)
Complex \(\alpha \pm i\beta\)\(x^\alpha\big[C_1\cos(\beta\ln x) + C_2\sin(\beta\ln x)\big]\)

Compare with 3.1: \(e^{mx}\) becomes \(x^m\), and \(x\) becomes \(\ln x\). That's because \(x = e^t\) turns an Euler equation into a constant-coefficient one.

Example 1 · distinct

\(x^2y'' - 2xy' - 4y = 0\)

Step 1. \(m(m - 1) - 2m - 4 = m^2 - 3m - 4 = (m - 4)(m + 1) = 0\)

Answer. \(\boxed{y = C_1x^4 + C_2x^{-1}}\)

Example 2 · repeated

\(x^2y'' + 5xy' + 4y = 0\)

Step 1. \(m^2 - m + 5m + 4 = m^2 + 4m + 4 = (m + 2)^2 = 0\)

Answer. \(\boxed{y = x^{-2}(C_1 + C_2\ln x)}\)

Example 3 · complex

\(x^2y'' + xy' + 9y = 0\)

Step 1. \(m^2 - m + m + 9 = m^2 + 9 = 0 \Rightarrow m = \pm 3i\)

Answer. \(\boxed{y = C_1\cos(3\ln x) + C_2\sin(3\ln x)}\)

Example 4 · non-homogeneous, using \(x = e^t\)

\(x^2y'' - 2xy' + 2y = x^3\)

Step 1. Put \(x = e^t\), \(D = \dfrac{d}{dt}\). Then \(xy' = Dy\) and \(x^2y'' = D(D - 1)y\).

Step 2. \(\big[D(D - 1) - 2D + 2\big]y = e^{3t}\), i.e. \((D^2 - 3D + 2)y = e^{3t}\).

Step 3. \(y_c = C_1e^{t} + C_2e^{2t}\). \(y_p = Ae^{3t}\): \((9 - 9 + 2)A = 1 \Rightarrow A = \tfrac12\).

Step 4. Back to \(x\) (\(e^t = x\)): \(\boxed{y = C_1x + C_2x^2 + \tfrac{1}{2}x^3}\)

Check \(y_p = \tfrac12x^3\): \(x^2(3x) - 2x\left(\tfrac32x^2\right) + x^3 = x^3\). ✓

3.4Differential Operator

Let \(D = \dfrac{d}{dx}\), so \(Dy = y',\ D^2y = y''\), and so on. Then \(ay'' + by' + cy = g\) is written as

\[ f(D)\,y = g(x), \qquad f(D) = aD^2 + bD + c. \]

Constant-coefficient operators factor like polynomials and commute: \((D - 2)(D - 3) = (D - 3)(D - 2) = D^2 - 5D + 6\). The particular integral is written \(y_p = \dfrac{1}{f(D)}g(x)\), where \(\dfrac1D\) means "integrate".

Short-cut rules for \(y_p = \dfrac{1}{f(D)}g(x)\)

1. Exponential. \(\dfrac{1}{f(D)}e^{ax} = \dfrac{e^{ax}}{f(a)}\), if \(f(a) \ne 0\).
If \(f(a) = 0\) with \(f(D) = (D - a)^k\phi(D)\), \(\phi(a) \ne 0\): \(\dfrac{1}{f(D)}e^{ax} = \dfrac{x^k e^{ax}}{k!\,\phi(a)}\).

2. Sine / cosine. Replace \(D^2\) by \(-a^2\): \(\dfrac{1}{f(D^2)}\sin ax = \dfrac{\sin ax}{f(-a^2)}\) (same for \(\cos\)), if \(f(-a^2) \ne 0\).
Failing case: \(\dfrac{1}{D^2 + a^2}\sin ax = -\dfrac{x\cos ax}{2a}\), \(\ \dfrac{1}{D^2 + a^2}\cos ax = \dfrac{x\sin ax}{2a}\).

3. Polynomial \(x^n\). Write \(\dfrac{1}{f(D)} = [1 \pm \phi(D)]^{-1}\), expand by the binomial series up to \(D^n\), and apply to \(x^n\).

4. Exponential shift. \(\dfrac{1}{f(D)}\big(e^{ax}V\big) = e^{ax}\dfrac{1}{f(D + a)}V\).

Example 1 · rule 1

\((D^2 - 3D + 2)y = e^{3x}\)

Step 1. \(y_c\): \((m - 1)(m - 2) = 0\), so \(y_c = C_1e^x + C_2e^{2x}\).

Step 2. \(y_p = \dfrac{e^{3x}}{9 - 9 + 2} = \dfrac{e^{3x}}{2}\)

Answer. \(\boxed{y = C_1e^x + C_2e^{2x} + \tfrac12e^{3x}}\)

Example 2 · rule 1, failing case

\((D^2 - 3D + 2)y = e^{x}\) (same as Example 4 of 3.2.1)

Step 1. \(f(1) = 0\). Write \(f(D) = (D - 1)(D - 2)\), so \(k = 1,\ \phi(D) = D - 2,\ \phi(1) = -1\).

Step 2. \(y_p = \dfrac{x e^x}{1!\,(-1)} = -xe^x\). Same answer as before. ✓

Example 3 · rule 2

\((D^2 + 4)y = \sin 3x\): \(\ y_p = \dfrac{\sin 3x}{-9 + 4} = \boxed{-\tfrac15\sin 3x}\)

\((D^2 + 4)y = \cos 2x\): \(f(-4) = 0\), failing case: \(\ y_p = \boxed{\dfrac{x\sin 2x}{4}}\)

Example 4 · rule 3

\((D^2 + D)y = x^2\)

Step 1. \(\dfrac{1}{D(1 + D)}x^2 = \dfrac1D(1 + D)^{-1}x^2 = \dfrac1D(1 - D + D^2 - \cdots)x^2\)

Step 2. \((1 - D + D^2)x^2 = x^2 - 2x + 2\). (Stop at \(D^2\): higher powers give 0.)

Step 3. \(\dfrac1D\) means integrate: \(y_p = \dfrac{x^3}{3} - x^2 + 2x\).

Answer. \(y_c = C_1 + C_2e^{-x}\), so \(\boxed{y = C_1 + C_2e^{-x} + \tfrac{x^3}{3} - x^2 + 2x}\)

Check: \(y_p' = x^2 - 2x + 2,\ y_p'' = 2x - 2\), sum \(= x^2\). ✓

Example 5 · rule 4

\((D - 1)^2y = xe^{x}\)

Step 1. \(y_p = \dfrac{1}{(D - 1)^2}e^{x}x = e^{x}\dfrac{1}{(D + 1 - 1)^2}x = e^{x}\dfrac{1}{D^2}x\)

Step 2. Integrate twice: \(\dfrac{1}{D^2}x = \dfrac{x^3}{6}\).

Answer. \(\boxed{y = (C_1 + C_2x)e^x + \tfrac16x^3e^x}\)
